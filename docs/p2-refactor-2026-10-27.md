## 三、稳定性增强（线 B）

### 崩溃恢复
- `DirectorAgent.recoverAll`：应用启动后扫描全部项目 `director-state.json`，把残留 `running=true / paused=true` 的状态降级为中断（running 阶段转 `error`、补「应用重启中断」日志），避免 UI 永久转圈、断点续跑入口被锁死。
- `directorStateMachine.hydrateImpl`：用户打开项目时的懒加载恢复，与 recoverAll 互补；恢复后不自动重启流水线（需 ComfyUI 在跑）。
- 孤儿临时文件清理：`before-quit` 统一收尾，配合 tmp 目录防护。

### childProcessManager
- 新建 `src/main/core/childProcessManager.ts`（192 行），统一登记/超时 kill/batch kill 子进程。
- 已接入：`ffmpegService`、`ttsService`（wav→mp3 转换）。
- `before-quit` 调用 `childProcessManager.killAll('before-quit')`，防退出后孤儿进程残留。
- 配套单测 `tests/unit/childProcessManager.spec.ts`（5 用例：登记/超时自动 kill/killAll 批量 kill 等）。

### retry-matrix 文档
- 路径：`docs/retry-matrix-2026-10-27.md`。
- 关键发现：瞬时错误（429/5xx/网络抖动）退避重试；取消信号在重试等待循环中通过 `CANCELLED` 哨兵优先打断，不等退避结束。

### 资源泄漏排查
- `before-quit` 链路补齐：cancel 流水线 → cancelAll 队列 → 断 ComfyUI WS → MCP 子进程 dispose → childProcessManager.killAll，5s 超时兜底强退。
- `clearState`：前端切项目时清 states/cancelled/gates/waiters/logSeq 等 13 个 Map/Set，防幽灵流水线跨项目泄漏（本次补了单测覆盖）。
- sendToWindow 对已销毁窗口静默丢弃，避免对销毁 webContents send 抛错。

## 六、未做项及原因（诚实标注）

- **renderShot 664 行闭包未拆**：捕获 25+ 可变局部变量，强行拆函数会改行为/闭包语义，按硬约束保留。
- **conversationService t* 工具 830 行未外移**：与 `conversationTools*.ts` 已分叉，接线会改变运行行为，保留现状。
- **ComfyUI spawn 未纳入 childProcessManager**：detached 长生命周期进程，与短生命周期 ffmpeg/TTS 语义不同，不统一纳管。
- **fluent-ffmpeg 内部 spawn 未拦截**：库内部管理子进程，外部拦截成本高、收益低。
- **coverage branches 18.06% 低于 20% 阈值**：已知，多为原生 IO 重服务（ffmpegService 7.6%、ttsService 2.0%、faceDetector 8.8%），单测难覆盖，需后续专项补测。
- **lint 剩余 40 warning**：全部为已注释/配置层说明的项——`let x=...;x=...` 历史模式（eslint 配置已注释降 warn）、IPC 边界/monkeypatch/CANCELLED 哨兵/控制字符清洗正则/测试夹具的行内 disable 注释。未为 0 warning 重写业务代码。
